CRF から SDTM へ

1人の架空の患者で見る、データの標準化（入力を変えると右の表がその場で変わります）

架空の試験 SPH2026（Drug X とプラセボの比較）に参加した1人の患者です。左が施設で記録する画面（CRF）、右が提出用の表（SDTM の DM ドメイン）です。

CRF患者背景

日付は「令和8年4月8日」「2026年4月8日」「2026/4/8」のどれで入れても構いません。生年月日を変えると年齢が、初回投与日を変えると全ドメインの試験日（--DY）が変わります。

この画面のポイント

  1. DM は1人＝1行。どの試験でも同じ変数名・同じ順番で並ぶ
  2. 和暦でも西暦でも、日付は ISO 8601（YYYY-MM-DD）に揃える（BRTHDTC・RFSTDTC など）
  3. 性別は「女性」ではなく、統制用語の F（M・F・U）
  4. USUBJID は「試験-施設-被験者番号」で、試験全体で一意。ほかの全ドメインがこの値でつながる
  5. 年齢（AGE）は生年月日と基準日から計算する。ここでは初回投与日（RFSTDTC）時点

SDTMDM（Demographics）

列名をクリックすると、ここに変数の意味が出ます。

    CRF は「1回の来院＝1行、検査項目が横に並ぶ」形（横持ち）。SDTM は「1つの検査値＝1行」の形（縦持ち）にします。

    CRFバイタルサイン

    数値を消すとその行が消え、「測定不能」などの文字を入れると数値の列（VSSTRESN）が空になります。

    この画面のポイント

    1. CRF の3行（来院）× 5列（項目）が、SDTM では 15行になる（横持ち → 縦持ち）
    2. 検査の名前は、施設の言葉ではなく統制用語の VSTESTCD・VSTEST（SYSBP・Systolic Blood Pressure など）
    3. ORRES は記録どおりの文字、STRESN は計算に使う数値。「36.50」は STRESC で「36.5」になる
    4. 単位も統制用語（脈拍は「回/分」ではなく beats/min、体温は C）
    5. 試験日（VSDY）は初回投与日が 1日目。前日は −1 日目で、0日目は無い

    SDTMVS（Vital Signs）

    列名をクリックすると、ここに変数の意味が出ます。

      施設が書いた言葉（逐語）と、辞書（MedDRA）で引いた用語は別の変数に入れます。日付が一部しか分からないときは、分かるところまでを書きます。

      CRF有害事象

      事象名を「めまい」など一覧に無い言葉に変えると、辞書で引けない状態を再現できます。発現日の「2026年5月」は日が分からない例です。

      この画面のポイント

      1. AETERM は報告された言葉、AEDECOD は MedDRA の基本語（PT）、AEBODSYS は器官別大分類（SOC）
      2. 「発熱」は報告どおり FEVER、辞書では Pyrexia。言葉と辞書の用語は一致しなくてよい
      3. 提出用のデータは英語で作る。日本語が残ると赤く表示される
      4. 発現日が「2026年5月」なら AESTDTC は 2026-05。日を勝手に補わず、試験日（AESTDY）も計算しない
      5. 重症度・重篤・転帰は統制用語（MILD・Y/N・RECOVERED/RESOLVED など）

      SDTMAE（Adverse Events）

      列名をクリックすると、ここに変数の意味が出ます。

        記録された単位のままの値（ORRES）と、試験で決めた標準の単位に換算した値（STRESN）を並べて持ちます。

        CRF臨床検査

        基準範囲（デモ用の値）：血糖 70〜109 mg/dL、ALT 10〜40 U/L。この試験では、血糖の標準単位を mmol/L と決めたことにしています。

        この画面のポイント

        1. 血糖は記録どおり mg/dL（LBORRES）と、換算した mmol/L（LBSTRESN）の両方を持つ
        2. ALT のように単位が同じなら、ORRES と STRESC は同じ値になる
        3. 基準範囲と比べた結果（LBNRIND：LOW・NORMAL・HIGH）も1つの変数として持つ
        4. 4週後の ALT の高値は、③ の有害事象「肝機能異常」と、USUBJID と日付で突き合わせられる

        SDTMLB（Laboratory Test Results）

        列名をクリックすると、ここに変数の意味が出ます。
          CRF（施設ごと・試験ごとの画面）→ 変数名・値の書き方・表の形を揃える →SDTM（どの試験でも同じ形）→ADaM（解析用）

          まとめ

          1. CRF の画面の数と、SDTM の表の数・行の数は一致しない（この例では、バイタルの1画面が VS の15行になる）
          2. 揃えるのは3つ：変数名（VSTESTCD など）、値の書き方（ISO 8601、統制用語、英語）、表の形（1行に何を置くか）
          3. 形が決まっているから、誰が作ったデータでも同じプログラム・同じ審査の手順で読める
          4. 日本の試験で特に引っかかるのは、和暦・日本語の記録・施設ごとの単位と基準範囲
          架空の試験・架空の患者のデータです。説明のため SDTM の変数は一部に絞っています（実際の提出データには、ほかにも必要な変数があります）。MedDRA の用語と基準範囲は例示です。このページは通信をせず、入力はブラウザの中だけで処理します。
